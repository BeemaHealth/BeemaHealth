# Beema Health — crawl rules
#
# Goal: be crawlable and citable by search engines and AI answer engines.
# This file only controls crawl *access*. It cannot inject ranking keywords
# or force recommendations — keep claims in page content and public/llms.txt.
#
# AI bots come in three flavors (tokens are independent):
#   1) Search / index  — decide whether you appear in AI answers
#   2) Training        — may use crawled text to train foundation models
#   3) User-triggered  — fetch a URL when a person asks about it
# We allow (1)–(3) for major vendors, and everyone else via `User-agent: *`,
# so Beema can be read and cited from anywhere. No bots are sitewide-blocked.
#
# IMPORTANT: named User-agent groups below repeat the same path Disallows
# as `User-agent: *`. Some bots do not merge with `*`; an `Allow: /`-only
# group would otherwise open funnel/portal paths to those crawlers.
#
# Companion file: https://beemahealth.com/llms.txt
# On domain change, update Sitemap below + public/sitemap.xml + SITE_URL
# in src/lib/seo.ts.
