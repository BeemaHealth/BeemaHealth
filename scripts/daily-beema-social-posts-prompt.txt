### Per-post trackable links (X, Reddit, GBP only)

Pattern:
https://beemahealth.com/waitlist/?utm_source=SOURCE&utm_medium=MEDIUM&utm_campaign=CAMPAIGN&utm_content=CONTENT

Where:
- DATE = today YYYY-MM-DD
- DATECOMPACT = YYYYMMDD
- RANDOM = fresh 3–4 char alphanumeric id (unique per post)
- utm_campaign = daily_DATE  (example: daily_2026-07-23)
- utm_medium = social (organic) · gbp for Google Business Profile
- X: utm_source=x , utm_content=x_post_1_DATECOMPACT_RANDOM …
- Reddit: utm_source=reddit , utm_content=reddit_post_1_DATECOMPACT_RANDOM
- GBP: utm_source=google , utm_medium=gbp , utm_content=gbp_post_1_DATECOMPACT_RANDOM

Never include ga_debug=1 on published links.

Optional local generator:
  npm run utm -- daily-pack
  npm run utm -- bio-links

**Copy/paste hygiene:**
- Paste URLs as plain text with literal `=` and `&` — never `%3D` / `%26`.
- Do NOT use Gmail “Copy link address” (adds `source=gmail` and breaks GA).
- Broken look: `…?utm_source%3D…&source=gmail` — never post those.
- X `t.co` shortening is fine if the destination UTMs are clean.

Under each X / Reddit / GBP post in the email:
🔗 Trackable link: [full URL with UTMs]

Do not shorten URLs unless the platform requires it.
